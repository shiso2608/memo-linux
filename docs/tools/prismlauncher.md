## パッケージインストール

1. インストール

```bash
sudo pacman -S --needed prismlauncher jre8-openjdk jre17-openjdk jre21-openjdk
```

2. 確認: Java

```bash
archlinux-java status
```

## 初期設定

1. **起動と言語設定**:  
   Prism Launcher を起動し、言語で **日本語** を選択して次へ進む。
2. **Java の選択**:  
   検出された Java の中から適切なものを選択する（通常は最新のもので問題ない）。
3. **アカウントの連携**:
   - 右上の **アカウント** > **アカウントの管理** を開く。
   - **Microsoft アカウントを追加** をクリックする。
   - 表示されたコードを Web ブラウザで入力し、ログインを完了する。

## インスタンスの作成

例として FTB Skies 2 を導入する手順。

1. **追加**:  
  メイン画面の **インスタンスを追加** をクリックする。
2. **プラットフォーム選択**:  
  左メニューから **CurseForge** (または FTB, Modrinth) を選択する。
3. **検索**:  
  検索窓に `FTB Skies` と入力し、リストから **FTB Skies 2** を選択して **OK** をクリックする。
4. **外部 Mod のダウンロード**:
   - ライセンスの関係で自動取得できない Mod がある場合、「不足している Mod があります」と表示する。
   - **不足 Mod を開く** をクリックするとブラウザが起動する。
   - ブラウザでダウンロードされたファイルを、Prism Launcher の指示されたフォルダ（通常は自動で開きます）に配置する。
5. **完了**:  
  全ての Mod が揃ったら **OK** をクリックして作成を完了する。

## メモリ割り当ての変更

1. インスタンスを右クリックして **編集** を選択する。
2. **設定** > **Java** タブを開く。
3. **最大メモリ割り当て** を環境に合わせて調整する (例: 4096 MB や 8192 MB)。
