## パッケージをインストール

```bash
sudo dnf install neovim
```

## 起動/終了

|コマンド|説明|
|:---:|---|
|ターミナルで `nvim`|起動|
|ターミナルで `nvim (ファイル名)`|ファイルを指定して起動|
|`:q`|終了|
|`:q!`|変更を破棄して終了|
|`:qa`|全てのバッファを終了|

## ファイル操作

|コマンド|説明|
|:---:|---|
|`:e (ファイル名)`|ファイルを指定して開く|
|`:e .`|ファイルピッカーを開く|
|`:oldfiles`|最近開いたファイルの一覧を表示する|
|`:w`|保存|
|`:wa`|全てのバッファを保存|
|`:wq`|保存して終了|

## モード

|コマンド|説明|
|:---:|---|
|他のモードで `Esc`|ノーマルモードにする|
|`i`|インサートモードにする (カーソルは前になる)|
|`I`|インサートモードにする (カーソルは行の先頭になる)|
|`a`|インサートモードにする (カーソルは後ろになる)|
|`A`|インサートモードにする (カーソルは行の末尾になる)|
|`o`|インサートモードにする (下に新しい行を追加する)|
|`O`|インサートモードにする (上に新しい行を追加する)|
|`:`|コマンドモードにする|
|`v`|ビジュアルモードにする|

## カーソル

|コマンド|説明|
|:---:|---|
|`h`|左へ移動|
|`j`|下へ移動|
|`k`|上へ移動|
|`l`|右へ移動|
|`(数字)h`|入力した数字分、左へ移動|
|`(数字)j`|入力した数字分、下へ移動|
|`(数字)k`|入力した数字分、上へ移動|
|`(数字)l`|入力した数字分、右へ移動|
|`w`|次の単語の先頭へ移動|
|`e`|現在の単語の末尾へ移動|
|`b`|前の単語の先頭へ移動|
|`^`|行の先頭へ移動|
|`$`|行の末尾へ移動|
|`(`|前の文の先頭へ移動|
|`)`|次の文の先頭へ移動|
|`{`|前の段落へ移動|
|`}`|次の段落へ移動|
|`[[`|前のセクションへ移動|
|`]]`|次のセクションへ移動|

## 画面

|コマンド|説明|
|:---:|---|
|`gg`|ファイルの先頭へ移動|
|`G`|ファイルの末尾へ移動|
|`(行番号)G`|指定した行へ移動|
|`Ctrl + f`|1ページ分上へ移動|
|`Ctrl + b`|1ページ分下へ移動|

## テキスト

|コマンド|説明|
|:---:|---|
|`x`|カーソル位置の文字を切り取り|
|`dw`|カーソル位置から単語の末尾まで切り取り|
|`D`|カーソル位置から行の末尾まで切り取り|
|`dd`|現在の行を切り取り|
|`yw`|カーソル位置から単語の末尾までコピー|
|`yy`|現在の行をコピー|
|`p`|カーソル位置の後ろに貼り付け|
|`P`|カーソル位置の前に貼り付け|
|`u`|元に戻す|
|`Ctrl + r`|やり直す|
|`gc`|カーソルを動かした範囲のコメントを切り替える|
|`gcc`|カーソルのある行のコメントを切り替える|

> [!TIP]
> 複数行のコメント切り替えは、例えば `gc5j` と入力すると下方向の 5 行分のコメントを切り替えることができる。

## 検索/置換

|コマンド|説明|
|:---:|---|
|`/(検索文字列)`|検索をする|
|`n`|次の検索結果へ移動する|
|`N`|前の検索結果へ移動する|
|`Ctrl + l`|検索マーカーを削除する|
|`:s/(置換前文字列)/(置換後文字列)/フラグ`|現在の行の一番左の置換前文字列を置換をする|
|`:%s/(置換前文字列)/(置換後文字列)/フラグ`|ファイル全体の置換をする|
|`:'<,'>s/(置換前文字列)/(置換後文字列)/フラグ`|選択範囲の置換をする|
|`:(行番号),(行番号)s/(置換前文字列)/(置換後文字列)/フラグ`|指定した行番号間の置換をする|

> [!TIP]
> 置換のフラグは下記。
> - `g`: 置換前文字列に合致する文字列を全て置換する。

> [!IMPORTANT]
> 選択範囲置換のコマンド `'<,'>` は、ビジュアルモードで `:` を入力すると自動で挿入されるため手打ちする必要は無い。
