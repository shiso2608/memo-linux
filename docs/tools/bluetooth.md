# Bluetooth

Arch LinuxにおけるBluetoothのセットアップと管理手順。

## 動作確認済み環境

- **レシーバー:** TP-LINK UB500
- **ヘッドセット:** JBL LIVE770NC

---

## 1. セットアップ

### パッケージインストール

Bluetooth本体と、PipeWire環境でオーディオを使用するために必要なパッケージをインストールします。

```bash
sudo pacman -S --needed bluez bluez-utils pipewire-pulse wireplumber
```

### サービスの有効化

Bluetoothサービスを有効化し、即時起動します。

```bash
sudo systemctl enable --now bluetooth
```

---

## 2. デバイスの認識確認

USBレシーバーが正常に認識されているか確認します。

```bash
lsusb
```

出力結果にレシーバー名、または `Realtek` などのチップセット名が表示されていれば正常です。

---

## 3. 機器のペアリングと接続

新しい機器を追加、または再接続する際の手順です。

1. **準備:** 接続する機器をペアリングモードにします。
2. **ツールの起動:** ターミナルで `bluetoothctl` を起動します。
   ```bash
   bluetoothctl
   ```
3. **対話型コマンドの実行:**
   ```bash
   power on         # 電源をオン
   agent on         # エージェントを有効化
   default-agent    # デフォルトエージェントとして設定
   scan on          # スキャンを開始
   ```
4. **接続の実行:** スキャン結果から対象機器の **MACアドレス**（例: `XX:XX:XX:XX:XX:XX`）を確認し、以下の順で実行します。
   ```bash
   pair [MACアドレス]
   trust [MACアドレス]
   connect [MACアドレス]
   ```
5. **終了:** 接続完了後、ツールを終了します。
   ```bash
   exit
   ```

## 4. オーディオプロファイルとコーデック

接続したヘッドセットの用途に合わせて、プロファイルとコーデックを選択できます。

### A2DP (High Fidelity Playback)

音楽鑑賞用の高音質モード。

| コーデック | 特徴                                                                   |
| :--------- | :--------------------------------------------------------------------- |
| **AAC**    | **推奨設定**。Apple製品やJBL製品で広く採用される高音質・低遅延な方式。 |
| **SBC-XQ** | PipeWire独自の高ビットレート設定。標準SBCより大幅に音質が向上。        |
| **SBC**    | 標準的なコーデック。互換性は高いが音質は平均的。                       |

### HSP/HFP (Headset Head Unit)

マイクを使用した通話用のモード。

| コーデック | 特徴                                                 |
| :--------- | :--------------------------------------------------- |
| **mSBC**   | ワイドバンド対応。通話用としては比較的高音質。       |
| **CVSD**   | 従来の通話コーデック。帯域が狭く、電話のような音質。 |
