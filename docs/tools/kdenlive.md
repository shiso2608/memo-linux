# Kdenlive

## 設定内容

上部メニューの 「設定」 -> 「Kdenlive の設定」 を開きます。

### プロキシクリップの有効化

1. 左メニューから 「Proxy Clips」 を選択します。
2. 「Enable proxy clips」 にチェックを入れます。
3. 「Generate for videos larger than:」 にチェックを入れ、値を 1000（またはそれ以下）にします。

### スレッドの割り当て数変更

1. 左メニューから 「環境」 を選択します。
2. 「Concurrent threads:」 に 4 などの値を入力します。

## 書き出し手順

1. 上部メニューの「レンダリング」を開きます。
2. 「Hardware Acceleration」->「VAAPI H264」を選択します。
3. 左下の「ファイルにレンダリング」をクリックします。
