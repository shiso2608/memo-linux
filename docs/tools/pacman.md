## 問い合わせ

- インストール済みのパッケージを全て表示する。

```bash
pacman -Q
```

> [!TIP]
> `pacman -Q (パッケージ名)`: 特定のパッケージを表示する。

- 依存関係を省き、明示的にインストールしたパッケージを表示する。

```bash
pacman -Qe
```

## 同期

- パッケージをインストールする。

```bash
sudo pacman -S (パッケージ名)
```

> [!TIP]
> `--needed`: 最新バージョンがインストールされていたらスキップする。

- パッケージを検索する。

```bash
pacman -Ss (キーワード)
```

- システム全体を更新する。

```bash
sudo pacman -Syu
```

## 削除

- パッケージを削除する。

```bash
sudo pacman -R (パッケージ名)
```

- 依存関係も含めて、パッケージを削除する。

```bash
sudo pacman -Rs (パッケージ名)
```

- 孤立した不要なパッケージを削除する

```bash
pacman -Qtdq | sudo pacman -Rns -
```
