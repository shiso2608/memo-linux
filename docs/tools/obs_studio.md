# OBS Studio

## 設定内容

OBS Studioを使って録画するための設定内容です。

### 出力

画面上部の出力モードを **詳細** に変更します。

#### 配信タブ

- **映像エンコーダ:** VAAPI H.264 on Navi 31 \[Radeon RX 7900 XT/7900 XTX/7900 GRE/7900M]
- **key-int-max (キーフレーム間隔):** 120
- **rate-control (レート制御方式):** Constant Bitrate (固定ビットレート)
- **b-frames (Bフレーム数):** 0
- **bitrate (ビットレート):** 6000
- **target-usage (速度と品質のバランス):** 4

#### 録画タブ

- **録画ファイルのパス:** `~/Videos/OBS`
- **録画フォーマット:** Matroska Video (.mkv)
- **映像エンコーダ:** VAAPI H.265 on Navi 31 [Radeon RX 7900 XT/7900 XTX/7900 GRE/7900M]
- **key-int-max (キーフレーム間隔):** 120
- **rate-control (レート制御方式):** Constant Quality (固定品質)
- **qpi / qpp / qpd (固定品質の設定):** 20
- **target-usage (速度と品質のバランス):** 1

#### リプレイバッファタブ

- **最大リプレイ時間:** 300s
- **最大メモリ:** 4096 MB

### 映像

- **基本 (キャンバス) 解像度:** 1920x1080
- **出力 (スケーリング) 解像度:** 1920x1080
- **FPS共通値:** 60

### ホットキー

- **録画開始:** Control + Shift + F10
- **録画停止:** Control + Shift + F10
- **出力をスクリーンショット:** Control + Shift + F9
- **リプレイを保存:** Control + Shift + F11

### 詳細設定

#### 録画

- **自動的に .mp4 に最多重化する:** チェック

## 手動での録画ファイルの再多重化

.mkv 形式で保存された録画ファイルを、手動で .mp4 形式に再多重化する方法を説明します。

1. メイン画面の左上メニューから 「ファイル」 -> 「録画の再多重化」 をクリックします。
2. 「OBS録画」の欄に、変換したい .mkv ファイルをドラッグ＆ドロップします（または右側の ... ボタンからファイルを選択します）。
3. 「対象ファイル」の欄に自動で .mp4 の保存先が表示されます。
4. 右下の 「再多重化」 ボタンをクリックします。
5. 「録画が再多重化されました」と表示されれば完了です。元のフォルダに .mp4 ファイルが生成されています。

## Wayland 環境のホットキー

Wayland 環境でフォーカスが OBS Studio から外れると、ホットキーが動作しなくなる不具合があります。
回避策として **[obs-cmd](https://github.com/grigio/obs-cmd)** を導入し、 OBS Studio の設定を行います。
**[obs-cmd](https://github.com/grigio/obs-cmd)** の使用方法はリンク先の README を参照すること。

1. メイン画面の左上メニューから 「ツール」 -> 「WebSocket サーバー設定」 をクリックします。
2. 「WebSocketサーバーを有効にする」のチェックを入れます。
3. 「認証を有効にする」のチェックを外します。
