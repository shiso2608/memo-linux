## パッケージをインストール

```bash
sudo dnf install tmux
```

## 起動

```bash
tmux
```

## 表記

|表記|キー|説明|
|:---:|:---:|---|
|`C-`|`Ctrl`|Ctrl キー|
|`M-`|`Alt`|Meta キー|
|`S-`|`Shift`|Shift キー|

> [!TIP]
> `Ctrl + b` がプレフィックスとして使用される。

## セッション

|コマンド|機能|
|:---:|---|
|tmux 内で `C-b` -> `d`|デタッチ|
|`tmux ls`|セッションを一覧で表示|
|`tmux a`|直前のセッションにアタッチ|
|`tmux a -t (セッション名)`|セッションを指定してアタッチ|
|`tmux kill-session`|全てのセッションを削除|
|`tmux kill-session -t (セッション名)`|特定のセッションを削除|

## コピーモード

|コマンド|機能|
|:---:|---|
|`C-b` -> `[`|モードの開始|
|`Space`|選択の開始|
|`Esc`|選択の解除|
|`^`|行頭に移動|
|`$`|行末に移動|
|`Ctrl + u`|半ページ上に移動|
|`Ctrl + d`|半ページ下に移動|
|`Enter`|コピー|
|`q`|モードの終了|

## キーバインド

- ペイン

|キーバインド|説明|
|:---:|---|
|`C-b >`|ペインメニューを表示|
|`C-b %`|ウィンドウを左右（水平）に分割|
|`C-b "`|ウィンドウを上下（垂直）に分割|
|`C-b *`|新しいフローティングペインを作成|
|`C-b ;`|直前にアクティブだったペインに移動|
|`C-b o`|次のペインを選択|
|`C-b Up / Down / Left / Right`|上 / 下 / 左 / 右のペインを選択（矢印キー）|
|`C-b C-o`|ペインの選択を順に切り替え|
|`C-b M-o`|ペインの選択を逆順に切り替え|
|`C-b {`|アクティブなペインを上のペインと入れ替え|
|`C-b }`|アクティブなペインを下のペインと入れ替え|
|`C-b E`|各ペインのサイズを均等に配置|
|`C-b C-Up / Down / Left / Right`|ペインのサイズを 上 / 下 / 左 / 右 に変更（1セル単位）|
|`C-b M-Up / Down / Left / Right`|ペインのサイズを 上 / 下 / 左 / 右 に 5セル単位で変更|
|`C-b z`|アクティブなペインのズーム（最大化/元に戻す）|
|`C-b f`|ペインを検索|
|`C-b q`|各ペインの番号を表示|
|`C-b m`|ペインのマーク状態を切り替え（トグル）|
|`C-b M`|マーク付けされたペインのマークを解除|
|`C-b x`|アクティブなペインを終了（削除）|

- ウィンドウ

|キーバインド|説明|
|:---:|---|
|`C-b <`|ウィンドウメニューを表示|
|`C-b c`|新しいウィンドウを作成|
|`C-b !`|ペインを新しいウィンドウとして分離|
|`C-b 0 ～ 9`|ウィンドウ 0 ～ 9 を選択|
|`C-b n`|次のウィンドウを選択|
|`C-b p`|前のウィンドウを選択|
|`C-b l`|直前にアクティブだったウィンドウを選択|
|`C-b w`|一覧からウィンドウを選択|
|`C-b '`|選択するウィンドウ番号を入力するプロンプトを表示|
|`C-b M-p`|アラート（通知）がある前のウィンドウを選択|
|`C-b M-n`|アラート（通知）がある次のウィンドウを選択|
|`C-b .`|現在のウィンドウを移動|
|`C-b S-Up / Down / Left / Right`|ウィンドウの表示領域を 上 / 下 / 左 / 右 に移動|
|`C-b DC`|ウィンドウの表示領域がカーソル位置に追従するようリセット (Deleteキー)|
|`C-b i`|ウィンドウの情報を表示|
|`C-b "`|現在のウィンドウ名を変更|
|`C-b &`|現在のウィンドウを終了（削除）|

- セッション管理

|キーバインド|説明|
|:---:|---|
|`C-b d`|現在のクライアントをデタッチ|
|`C-b (`|前のクライアントに切り替え|
|`C-b )`|次のクライアントに切り替え|
|`C-b L`|最後に使用したクライアントに切り替え|
|`C-b s`|一覧からセッションを選択|
|`C-b $`|現在のセッション名を変更|
|`C-b D`|一覧からクライアントを選択してデタッチ|
|`C-b C-z`|現在のクライアントを一時停止（サスペンド）|

- その他

|キーバインド|説明|
|:---:|---|
|`C-b ?`|キーバインド（ヘルプ）一覧を表示|
|`C-b /`|キーバインドの説明を表示|
|`C-b C`|オプション設定のカスタマイズ画面を表示|
|`C-b :`|コマンド入力用のプロンプトを表示|
|`C-b ~`|メッセージ履歴を表示|
|`C-b t`|時計を表示|
|`C-b [`|コピーモードに移行|
|`C-b PPage`|コピーモードに入り上にスクロール (PageUpキー)|
|`C-b #`|すべてのペーストバッファの一覧を表示|
|`C-b =`|一覧からペーストバッファを選択|
|`C-b ]`|最新のペーストバッファを貼り付け|
|`C-b -`|最新のペーストバッファを削除|
|`C-b M-1`|均等水平レイアウトを設定（even-horizontal）|
|`C-b M-2`|均等垂直レイアウトを設定（even-vertical）|
|`C-b M-3`|メイン水平レイアウトを設定（main-horizontal）|
|`C-b M-4`|メイン垂直レイアウトを設定（main-vertical）|
|`C-b M-5`|タイル表示レイアウトを選択（tiled）|
|`C-b M-6`|反転メイン水平レイアウトを設定（main-horizontal-mirrored）|
|`C-b M-7`|反転メイン垂直レイアウトを設定（main-vertical-mirrored）|
|`C-b Space`|次のレイアウトを選択|
|`C-b r`|現在のクライアント画面を再描画|
|`C-b C-b`|プレフィックスキー自体（Ctrl+b）を送信|
